# UOBQ V1.10 — 弃牌堆明牌规则

## 新规则
- 自己的回合，既可从摸牌堆抽牌，也可点击弃牌堆最上方的明牌。
- 弃牌堆明牌必须立即替换自己四张牌中的一张；不能直接弃回，也不能使用其 Peek/Spy/Swap 技能。
- 换进手牌的弃牌堆卡牌保持正面向上，双方可见，后续回合不会自动翻回。
- 被替换掉的旧牌正面朝上移至弃牌堆顶部。
- 电脑同样可以选择弃牌堆的最上方明牌，并保持公开状态。
- Swap 交换牌时，明/暗状态随卡牌移动。
- 新摸牌堆摸到的牌用于替换时保留暗牌状态；结算时所有牌亮出。

## 技术检查
- JavaScript 语法检查通过。
- 牌面资源 0–13 和卡背保留。
- 测试环境阻止 Playwright 浏览器页面加载及脚本注入，未完成端到端点击验收，请在部署后的桌面与手机浏览器验证。

## 下一节点用户确认
请试一次“弃牌堆明牌 → 替换我的牌 → 明牌持续公开”，观察电脑是否也会取明牌；以及 Swap 时明牌是否始终公开。
