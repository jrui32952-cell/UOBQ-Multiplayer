# UOBQ Multiplayer V0.1 · 双人联机测试版

## 已实现
- 首页「多人联机」入口，创建 6 位房间码、邀请朋友加入；两位玩家各自使用浏览器操作
- Node.js 服务器保存牌堆、回合、双人暗牌、双方已知牌与累计分；实时推送不同的玩家视图
- 开局每人选择查看两张牌；公开给双方的是牌位编号，数值仅限查看者
- 每人四个固定牌位 #1–#4，不自动排序
- 抽牌、弃牌、替换；弃牌堆取最上方公开牌换入后始终正面朝上，且不能直接发动技能
- 7–8 偷看，9–10 侦查，11–12 交换；每次操作公开位置，不公开未授权的暗牌数值
- CABO 宣告后对手完成最后一回合，严格低点数成功记 0 分，否则原始点数 +10 分
- 每局累计计分；双方任一方达到 100 分时整场结束，低分获胜；复盘记录每小局分数
- 桌面与手机适配的双人网页

## 本地启动
需 Node.js 20 或更新版。无需 npm install。

```bash
npm start
```

打开 http://localhost:3000 ，点击首页「开始游戏 → 多人联机」；第二位玩家使用同一台电脑的另一个浏览器窗口或同一局域网内的另一台设备访问服务器地址，输入房间码加入。**注意：不是双击 index.html 直接打开，也不是只把静态文件上传 Netlify。**

## 上线说明
需要长期运行的 Node.js 服务器（例如 Render、Railway、Fly.io、VPS，取决于其当前产品支持）；运行 `npm start` 并将服务映射到平台提供的 `PORT`。前后端本测试版由同一个进程提供，因此无需配置跨域。Netlify 静态站单独上传无法运行这个服务器。

## 测试
```bash
npm test
```
运行核心规则安全测试。服务器重启后当前房间和历史全部消失；正式上线前必须加入持久化存储、断线重连/离线处理、房间有效期与权限加强。第一阶段只支持 **2 人**，不支持观战或 3 人以上。当前无注册和历史账号体系。

## 技术
- 后端：Node.js 原生 HTTP + Server-Sent Events (SSE)，玩家提交操作使用 POST，服务器实时广播各自的脱敏状态
- 前端：原生 HTML/CSS/JavaScript
- 不依赖第三方 npm 包
